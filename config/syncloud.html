Registration is closed on this server: the token above is required to add a phone.

  1. Install FMD from F-Droid on the phone.
  2. In FMD, open the server settings and set the server URL to {{ .Url }}.
  3. Pick a user name and a password, and paste the token above as the registration token.
  4. Register. Then sign in at {{ .Url }} with that user name and password to locate the phone.

The password you choose in step 3 also decrypts the phone's data in your browser - the server never sees it, and it cannot be reset. Register each phone separately. Keep this token private; anyone who has it can create accounts on this server.
